Бизнес-Аналитик - это специалист, который сидит между заказчиком и командой разрабочиков. он помогает понять реальные потребности бизнеса и перевести их на понятный язык для разработчиков.

**Ключевые обязанности** (Что делает BA)
- *Сбор и анализ требований*: Общается с заказчиками, проводит интервью, выявляет истинные боли и цели бизнеса (а не то, что «просто хочется» клиенту).
- *Моделирование бизнес-процессов*: Изучает текущее положение дел (AS IS) и проектирует будущее (TO BE), используя специальные нотации (BPMN, UML, EPC).
- *Формализация и документирование*: Создает спецификации, пользовательские истории (User Stories), варианты использования (Use Cases) и критерии приемки (Acceptance Criteria).
- *Постановка задач и контроль*: Объясняет задачу разработчикам и тестировщикам, отвечает на их вопросы, помогает удерживать изначальный бизнес-смысл продукта.
