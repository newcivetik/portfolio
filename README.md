## Главный кейс

### [SellWhy: процессы, требования и модель данных реального продукта →](cases/sellwhy/README.md)

SellWhy — SaaS-конструктор интернет-магазинов одежды ([sellwhy.ru](https://sellwhy.ru)). Я его разработал, а потом разобрал как аналитик. В кейсе:

- процесс регистрации продавца в **BPMN 2.0** (с исходником `.bpmn`) и в **IDEF0**;
- **жизненный цикл заказа**, восстановленный по коду;
- **три расхождения** в правилах статусов и рекомендации по ним;
- **пользовательские истории** с критериями приёмки в формате Gherkin;
- **ER-модель**, **сценарий интеграции** с ЮKassa и **схема архитектуры**.
